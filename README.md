# 智素领航

智素领航是面向学生人工智能素养发展的信息技术学科智能教学平台。当前项目包含产品首页、登录功能和登录后工作台基础能力。

## 项目组成

- 前端：Node.js 22、Vue 3、TypeScript、Vite、Element Plus、Pinia、Axios。
- 后端：Python 3.11、FastAPI、Pydantic、SQLAlchemy。
- 数据库：MySQL 8，使用 UTF-8 多字节字符集。

## 前端启动

```powershell
npm run dev
```

## 后端启动

```powershell
python -m fastapi dev app/main.py
```

## 数据库说明

后端通过配置文件读取数据库连接信息。应用启动时会自动创建当前已实现的用户数据表。

用户表用于保存登录账号、密码、显示名称、角色、账号状态及创建、更新时间。登录时，后端会校验账号是否存在、账号是否启用以及密码是否匹配；校验通过后返回登录凭证。

## 当前功能

- 公开产品首页及平台流程展示。
- 首页弹出登录窗口。
- 用户名和密码登录校验。
- 登录状态保存与登录后工作台访问控制。

## 注意事项

当前演示版本按需求使用明文密码校验，仅适用于本地演示环境。正式部署前应改用安全的密码加密存储方式，并妥善保管登录凭证密钥。
